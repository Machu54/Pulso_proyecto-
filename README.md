# Pulso - Sistema de Monitoreo de Salud para Adultos Mayores[cite: 1]

## Objetivo
Crear un sistema digital e integral para monitorear en tiempo real la salud y seguridad de los adultos mayores en el hogar, proporcionando asistencia inmediata durante emergencias, facilitando el seguimiento médico y brindando tranquilidad a sus familias y doctores[cite: 1].

## Descripción General
Pulso es un ecosistema tecnológico diseñado para el cuidado de los adultos mayores[cite: 1]. Utiliza un smartwatch con Wear OS (Kotlin) para monitorear constantes vitales y detectar caídas[cite: 1], una aplicación móvil en React Native que envía alertas en tiempo real a familiares y cuidadores[cite: 1], un portal web en Vue.js y Laravel para que los médicos consulten historiales[cite: 1], y recordatorios de medicamentos por voz mediante Alexa[cite: 1]. Todo el sistema opera con base de datos MongoDB e implementación de cifrado de seguridad de extremo a extremo[cite: 1].
